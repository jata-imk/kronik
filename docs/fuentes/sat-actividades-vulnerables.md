# SAT Actividades Vulnerables

## Fuente

- Nombre: Actividades Vulnerables.
- Institucion: SAT.
- URL principal: https://wwwnp.sat.gob.mx/minisitio/ActividadesVulnerables/index.html
- Portal PLD preguntas frecuentes: https://sppld.sat.gob.mx/pld/interiores/preguntas.html
- Fecha de consulta: 2026-07-17.

## Resumen

SAT publica informacion sobre actividades vulnerables y criterios relacionados con operaciones de mutuo, prestamos o creditos en ciertos supuestos. Esta fuente se documenta solo como referencia, especialmente para escenarios donde la operacion no forme parte del sistema financiero.

## Requisitos Funcionales Derivados

- Registrar origen de recursos y destino del credito.
- Preparar modelo de alertas/revision cuando aplique.
- Documentar si una financiera opera dentro o fuera de supuestos de actividad vulnerable.

## Decisiones de Producto

- No usar esta fuente para codificar reglas automaticas sin revision legal.
- Mantenerla como referencia en el modulo PLD y cumplimiento.

## Pendiente de Validacion

- Confirmar aplicabilidad real segun figura juridica, operacion y producto.
