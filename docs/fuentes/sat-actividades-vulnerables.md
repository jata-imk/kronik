# SAT Actividades Vulnerables

## Fuente

- Nombre: Actividades Vulnerables.
- Institución: SAT.
- URL principal: https://wwwnp.sat.gob.mx/minisitio/ActividadesVulnerables/index.html
- Portal PLD preguntas frecuentes: https://sppld.sat.gob.mx/pld/interiores/preguntas.html
- Fecha de consulta: 2026-07-17.

## Resumen

SAT publica información sobre actividades vulnerables y criterios relacionados con operaciones de mutuo, préstamos o créditos en ciertos supuestos. Esta fuente se documenta solo como referencia, especialmente para escenarios donde la operación no forme parte del sistema financiero.

## Requisitos Funcionales Derivados

- Registrar origen de recursos y destino del crédito.
- Preparar modelo de alertas/revisión cuando aplique.
- Documentar si una financiera opera dentro o fuera de supuestos de actividad vulnerable.

## Decisiones de Producto

- No usar esta fuente para codificar reglas automáticas sin revisión legal.
- Mantenerla como referencia en el módulo PLD y cumplimiento.

## Pendiente de Validación

- Confirmar aplicabilidad real según figura jurídica, operación y producto.
