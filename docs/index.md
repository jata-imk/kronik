# Documentación Kronik

Este directorio usa una estrategia híbrida: Markdown + Diataxis + compatibilidad con Obsidian. La documentación debe mantenerse enlazada con rutas relativas para que funcione bien en editores, GitHub y una futura migración a Docusaurus.

## Secciones

- [Tutoriales](tutorials/index.md): guías paso a paso para comenzar.
- [How-to](how-to/index.md): recetas para tareas operativas concretas.
- [Referencia](reference/index.md): comandos, variables, seeders, conceptos y contratos técnicos.
- [Explicación](explanation/index.md): contexto, decisiones y lógica de negocio.
- [Backlog](todos/index.md): TODOs funcionales y técnicos.
- [Fuentes](fuentes/index.md): resúmenes de fuentes oficiales y regulatorias.

## Mantenimiento

Antes de cada commit, revisa si el cambio requiere actualizar tutoriales, how-to, referencia, explicación o backlog. Si el cambio modifica comportamiento visible, configuración, comandos, estructura de BD, deploy o reglas de negocio, debe quedar documentado.
