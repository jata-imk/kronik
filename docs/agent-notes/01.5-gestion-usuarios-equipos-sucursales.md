## Objetivo

Implementar el gobierno institucional de usuarios, equipos y sucursales. Los equipos definen permisos, las sucursales definen contexto operativo y cada cliente conserva una sucursal responsable con lectura global y escritura desde su contexto responsable.

## Estado actual

- Estado: en progreso.
- Ultima actualizacion: 2026-08-08.
- Ultimo punto estable: implementacion completa y verificada en la rama; cambios documentales previos preservados.

## Decisiones pendientes

- Ninguna decision de dominio pendiente para cerrar esta implementacion.
- El equipo actual define permisos Spatie; la sucursal actual define captura y escritura.
- Usuario-sucursal es muchos a muchos, con sucursal principal y actual.
- El cliente tiene una sucursal responsable; su lectura es global y su escritura requiere activar esa sucursal.
- Super Admin es global y no depende de membresias repetidas.
- Usuarios y equipos se desactivan sin borrado; una sucursal con usuarios activos o clientes no se puede desactivar.
