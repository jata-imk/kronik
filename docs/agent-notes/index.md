# Agent Notes

- [Backlog 03: productos crediticios](03-productos-crediticios.md)

Contexto operativo para continuar trabajo entre sesiones o equipos sin depender del historial de una conversacion.

## Fuente de verdad

- Notion define orden, alcance, prioridad y estado del producto.
- Los ADR en `docs/explanation/` conservan decisiones arquitectonicas aceptadas y su justificacion.
- Las secciones Diataxis documentan comportamiento, operacion y referencia duraderos.
- Agent Notes registra solamente el estado de ejecucion y el siguiente punto de continuacion.

No guardar secretos, credenciales, datos personales, respuestas sensibles de proveedores ni copias completas del backlog.

## Convencion

- Un archivo por backlog: `NN.N-nombre-corto.md` o `NN-nombre-corto.md`.
- Partir de [la plantilla](template.md).
- Actualizarlo al cambiar de rama, abrir o cerrar una PR, descubrir un bloqueo o entregar el backlog.
- Al finalizar, condensar la cronologia y dejar evidencia final, commit/PR y pendientes diferidos.
