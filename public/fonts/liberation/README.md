# Liberation Fonts 2.1.5

Unmodified TTF assets for the template editor and PDF renderer (Sans, Serif and Mono; regular, bold, italic and bold italic).

- Upstream: https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5
- Source archive: https://github.com/liberationfonts/liberation-fonts/files/7261482/liberation-fonts-ttf-2.1.5.tar.gz
- License: SIL Open Font License 1.1; see `LICENSE` and `AUTHORS`.

Fonts are served locally to the editor and embedded as data in PDF rendering. No runtime download is needed. Font binaries are unchanged; attribution/license whitespace was normalized without changing its wording.
